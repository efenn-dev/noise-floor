NOISE FLOOR (portable copy)

To play: double-click "Play Noise Floor.bat".
  - If Windows asks "Do you want to run this file?" or says it protected the PC, choose Run
    (or More info, then Run anyway). It's the game's own launcher.
  - The first start takes a little longer.

Installing on a PC: copy NoiseFloor.zip to the PC (the Desktop is fine), right-click it,
choose Extract All, then open the NoiseFloor folder and double-click "Play Noise Floor.bat".
You can right-click the .bat and choose Send to > Desktop (create shortcut) for an icon.

Saved games: the saves that came with this copy are brought across the first time it runs,
but only if this PC has no Noise Floor saves yet. They live in
%APPDATA%\Godot\app_userdata\Noise Floor, not in this folder, so deleting or replacing this
folder never loses them.

Updating: automatic. Each time you start the game, the launcher checks the family drive
(the folders listed in update_from.txt) and brings in a newer version if there is one. When
it says "Updating", leave the black window open until it says "Updated" (usually under a
minute); the game starts by itself after that. If it's closed early, the old version is kept
and the update tries again next time. If the drive can't be reached, it just plays the
version it has.
To update by hand instead: extract the new NoiseFloor.zip and replace the old NoiseFloor folder.
The saves stay where they are either way.

If the game runs slowly: Esc > Settings > Graphics > Low.

The version is on the title screen (bottom corner).
